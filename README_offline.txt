FPS OFFLINE (single-player) package
=====================================
Runs fully offline. Includes only the built frontend + a tiny local server.
No node_modules, no internet, no backend server required.

Requirements:
  - Node.js installed on the machine (https://nodejs.org)

How to run (Windows):
  1. Double-click  serve.bat
  - or run:  node serve.mjs
  2. Browser opens automatically to the game.
  3. Click "单人训练" (Solo Training) to play with no network.

How to run (Mac/Linux):
  - node serve.mjs   (then open the printed URL)

Notes:
  - Single-player mode is 100% local: no network or backend needed.
  - Enemies are AI bots that behave like real players.
  - For online multiplayer, use the full package (FPS_Game_Full.zip).
  - Press Ctrl+C in the console to stop the server.
