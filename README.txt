Rapid Fire - FPS Game (campus map)
====================================

One-click run (Windows):
  1. Unzip this folder anywhere.
  2. Double-click "run.bat".
  3. The game opens automatically at http://localhost:5175

How to play:
  - Start game -> create or join the "campus" room.
  - At least 2 players are required to press "Start Game".
  - Open a second browser tab to join as player 2 and test multiplayer.

Servers (started automatically):
  - Frontend (Vite):  http://localhost:5175
  - Backend  (WebSocket): ws://localhost:3002

Notes:
  - First launch auto-installs dependencies (needs internet, ~1 min).
    After that it runs fully offline.
  - To play with friends on the same LAN, use the "Network"
    URL printed by Vite in this window.
  - Stop the game by closing this window or pressing Ctrl+C.
